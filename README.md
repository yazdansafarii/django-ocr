## 🇺🇸 English Version

### 📝 Description
This is a powerful web-based application built with **Django** and **EasyOCR**. It allows users to upload images or PDF files and accurately extract text while maintaining the original structure.

### ✨ Key Features
* **Image OCR:** Extract text from various image formats (JPG, PNG, etc.).
* **PDF Processing:** Full support for extracting text from PDF documents.
* **High Accuracy:** Powered by EasyOCR for reliable character recognition.
* **User-Friendly Interface:** Clean UI built with HTML and CSS.

### 🛠 Technologies Used
* **Backend:** Python, Django
* **OCR Engine:** EasyOCR
* **Frontend:** HTML5, CSS3

### 🚀 Installation & Setup
1.  **Clone the repo:**
    ```bash
    git clone [https://github.com/yourusername/DJANGO-PDF-IMAGE-OCR.git](https://github.com/yourusername/DJANGO-PDF-IMAGE-OCR.git)
    cd DJANGO-PDF-IMAGE-OCR
    ```
2.  **Install dependencies:**
    ```bash
    pip install django easyocr
    ```
3.  **Run migrations:**
    ```bash
    python manage.py migrate
    ```
4.  **Start the server:**
    ```bash
    python manage.py runserver
    ```
